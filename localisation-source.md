   The `t()` helper returns the raw key path if a translation is missing (e.g. `form.unknownKey`). No missing keys detected at export time.
   Language button `aria-label` values use fixed `LANG_SELECT_LABELS` in the target language, not the active UI language.
   Language button `title` tooltips use `language.german`, `language.english`, etc. from the **active** UI locale.

   - Brand mark `Triple Gelato Triathlon` in logo and footer (intentionally Latin)
   - JSON-LD structured data description (German only, static)
   - Footer email placeholder address
   - `https://` website field placeholder
   - Progress indicator numeric format `N / 5`
   - Language selector glyphs (flags / ع) and expand chevron ▾
   - Fixed `LANG_SELECT_LABELS` for language-switcher `aria-label` attributes

10. **Translation keys whose meaning differs materially between languages:**
    Manual editorial review recommended. Automated notes:
    - **Register/formality:** German copy predominantly uses formal *Sie*; English uses *you*; Italian/Turkish/Arabic vary by locale conventions.
    - **nav.faq / form fields “Website”, “Vegan”, “FAQ”:** Identical or near-identical strings in multiple languages (language.english, language.german).
    - **Keys identical in all five languages (9 total):** form.age10to13, form.age14to17, form.age18plus, form.age6to9, language.arabic, language.english, language.german, language.italian, language.turkish
    - **Keys where EN text exactly equals DE text (22 total):** form.age10to13, form.age14to17, form.age18plus, form.age6to9, form.dietaryVegan, form.name, form.orgSponsor, form.orgWebsite, form.stepLabel2, form.stepLabel4, language.arabic, language.english, language.german, language.italian, language.selectArabic, language.selectEnglish, language.selectGerman, language.selectItalian, language.selectTurkish, language.turkish, nav.faq, partners.sponsor

11. **Arabic RTL support:**
    Yes. Implemented in `script.js` `applyTranslations()`: `document.documentElement.dir` is set to `rtl` when language is `ar`, otherwise `ltr`.
    CSS in `styles.css`: `html[lang="ar"]` font overrides (Noto Sans Arabic); `html[dir="rtl"]` rules for text alignment, form controls, progress meta, hero collage kept LTR; CTA arrows flip to ←.

12. **Language-specific layout handling currently present:**
    - Desktop: five language buttons in a row (`.lang-switcher-row`)
    - Mobile: compact current-language button + popover (`.lang-switcher-compact`)
    - Arabic: RTL document direction, Arabic font stack, reversed checkbox/radio flex direction, RTL form nav, non-mirrored hero images
    - `.btn-arrow` hover transform mirrored for RTL
    - Stage card cycle layout uses `direction: rtl` on desktop for visual alternation (all languages)
